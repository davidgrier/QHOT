The Tasks

Every task also has delay: the number of frames to wait before it starts (default 0). A frame is a frame of video that QHOT displays. Positions are in pixels of the camera image.

TaskWhat it does Parameters
AddTweezer Adds one tweezer. x, y: where. If they are left out, the optical axis.
ClearTraps Removes every trap.none
Delay Waits. frames: how many (default 30).
Move Moves the marked traps and groups, each as a whole, so that the center of the marked traps reaches a place. Nothing is marked: it does nothing. x, y, z: the place. step: the most that a trap moves in one frame (default 1).
MoveTraps Moves every trap and group by a displacement. dx, dy, dz: how far (default 0). step: the most in one frame (default 1). selected_only: move only the marked traps.
BeginRepeat, Repeat Repeat the tasks between them. n (of Repeat): how many times the block runs in all (default 1).
LoadTraps Replaces the traps with those in a file that File → Save Traps or SaveTraps wrote. filename: the file. Required.
SaveTraps Saves the traps to a file. filename. If it is left out, a file with the time in its name in your data folder.
Snapshot Saves the video image to a picture file. filename. If it is left out, a file named from prefix (default snapshot) and the time, in your data folder.
StartRecording Starts recording the video, and goes on to the next task. filename: if it is left out, the file named in the recorder. nframes: the most frames (default 10000). nskip: record every Nth frame (default 1). overwrite: replace a file that exists (default no).
StopRecording Stops the recording.none
Record Records for as long as the task lasts, then stops. filename, overwrite as above. nframes: how many frames to record (default 0, which is until the queue is stopped).
