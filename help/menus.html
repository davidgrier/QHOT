Menus, Files and Keyboard Shortcuts

In the shortcuts, Ctrl is the Command key on a Mac. QHOT says what it did, or why it could not, in the status bar at the bottom of the window.

File

Open TrapsCtrl-O Replace the traps with those in a file.
Save TrapsCtrl-S Save the traps to the file that you last opened or saved, or to a new file if there is none.
Save Traps AsShift-Ctrl-S Choose a file to save the traps to.
Open Queue, Save Queue, Save Queue As The same for the queue of tasks.
Export Save Image saves the video image as it appears on the screen, without the trap markers, and Save Hologram saves the hologram on the SLM, each as a picture (PNG, JPEG or TIFF). The As items ask for a file name.
Preferences Save Settings saves the size and place of the window and the CGH calibration; Restore Settings goes back to them. QHOT does both by itself when it quits and starts.

Traps are saved in a file of type JSON, and a queue in a text file of type TOML. A file that is saved without a name from you gets the time in its name, and goes to the data folder in your home folder, where a new file never replaces an old one. If a file cannot be saved, QHOT says so and the file that was there is left as it was.

Edit

UndoCtrl-Z Undo the last operation on the traps.
RedoCtrl-Y (Shift-Command-Z on a Mac) Do again what was undone.
Toggle OverlayCtrl-\ Hide or show the trap markers.

Tasks

Add Trap Add a trap of the kind that you choose, on the optical axis.
Add TweezerCtrl-T Add a tweezer on the optical axis.
Clear TrapsCtrl-Backspace Remove every trap. This cannot be undone.
Queue Add a task to the queue.

Recorder

RStart recording, or stop if it is recording.
SStop recording or playing.

The mouse gestures for the traps are in Working with traps.
