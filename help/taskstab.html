Tasks Tab

The Tasks tab runs a queue: a list of steps that QHOT carries out, one after another, without your hands. A step can add or move traps, wait, take a picture, or start and stop a recording. See Running a queue of tasks for how to build one and The tasks for what each step does.

The panels

Queue
The tasks, in the order that they run. The task that is running is in bold on a violet background. Tasks that are done are gray, and a task that failed is red. Tasks that have not run yet can be dragged to a new place.
Background
Tasks that run alongside the queue, if there are any. The tasks that you add from the menu or from a queue file run in the queue.
Parameters
Click a task to show its parameters, and change them here. A task with no parameters shows nothing.

The buttons

Play / Pause
Starts the queue, or pauses it while it runs. Tasks that you add to a queue that is not running wait for you to press Play, so that you can look at them before they move anything.
Stop
Ends the running task and goes back to the first task of the queue, paused. The tasks stay in the list, and Play runs them again from the start.
Clear
Stops the queue and removes all of its tasks.

To remove one task, right-click it and choose Remove, or select it and press Delete or Backspace. The task that is running cannot be removed. When the last task is done, the queue is ready to run again from its first task.

The status bar says whether the queue is running, paused or idle. A step of the queue happens once for each frame of video that QHOT displays, which is up to 30 a second.
